# Zone Photos

The source of truth for the https://zone.photos photography portfolio website.

Images all rights reserved.

## Publishing images

The planned image publishing workflow is documented in [`zonepub/README.md`](zonepub/README.md).

ZonePub is intended as a local publishing assistant between digiKam, Hugo, and GitHub Pages. It keeps digiKam as the metadata source of truth and uses Git branches and pull requests to publish selected portfolio images.
